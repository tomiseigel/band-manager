BAND MANAGER v0.1

Abrí index.html en un navegador para probar la aplicación en tu Mac.
Los datos se guardan localmente en ese navegador.
Para instalarla como PWA en Android, publicá estos archivos en un sitio HTTPS (por ejemplo GitHub Pages).
No hay todavía cuentas, sincronización, importación CSV ni conexión con ticketeras.
Hacé respaldos desde Ajustes > Exportar respaldo.
No ingreses información confidencial hasta incorporar autenticación y almacenamiento seguro.
